# Orbit OS project memory

These files describe the repository **as it exists**. The root `orbitosMVPplan.md` and `orbitosUIskill.md` describe intended product behavior and visual design. Do not treat their proposed API, schema, or extension as shipped code.

- `architecture.md`: current components, planned integration, and trust boundaries.
- `contracts.md`: current client routes, extension rule and storage contracts, and environment variables.
- `testing.md`: commands, manual browser check, and remaining coverage.

Before changing a contract, check its callers, update this folder in the same PR, and state how compatibility was checked. Keep open work in `tasks/`, one file per task.
