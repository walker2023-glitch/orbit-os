# T-002: One-child chore-to-unlock vertical slice

**State:** Proposed  
**Depends on:** T-001 browser acceptance check and decisions in `docs/architecture.md`.

## Goal

A parent creates checkbox Must-Dos for one child; a paired extension receives limited child-scoped rules; the child completes tasks in a Smart Board; YouTube becomes available automatically within a stated sync interval.

## Before implementation

Define the parent, child, and device auth boundaries and the exact Focus Mode/unlock policy. Document API schemas and family scoping, choose day rollover, and check the proposed solution on the intended Chromebook. Build the backend and database incrementally; test the end-to-end state change and unauthorized access to parent routes. Defer photo proof, timers, and gamification.
